# UnitConverter

Prosta aplikacja na Androida napisana w Kotlinie z interfejsem przygotowanym w Jetpack Compose, przeliczająca jednostki metryczne na imperialne i odwrotnie.

## Testy

Projekt zawiera testy jednostkowe logiki przeliczania, obsługi zera i odrzucania wartości ujemnych.

## CI/CD

Workflow safe_build w Bitrise uruchamia testy jednostkowe, skanuje kod przez mobsfscan, buduje APK i udostępnia pliki wynikowe.
